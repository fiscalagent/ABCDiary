# ABCDiary

Голосовой дневник для КПТ-практики с локальным шифрованием и синхронизацией в Google Таблицы. PWA, ставится на телефон как обычное приложение.

Живая версия: https://fiscalagent.github.io/ABCDiary/

📖 **[Подробное руководство пользователя](docs/GUIDE.md)** — как пользоваться приложением, как создать и подключить Google Таблицу, разбор всех разделов и частые проблемы.

## Что это

Дневник для пациента, таблица для терапевта. Пациент пишет записи голосом или текстом — приложение шифрует их на устройстве и одной строкой кладёт в Google Sheet, к которому у терапевта есть доступ. Никакого бэкенда: всё работает между браузером, IndexedDB и Google Sheets API.

## Разделы приложения

### 💭 Эмоции (one-shot)

ABC-схема в одном проходе: время · дата · триггерная ситуация · мысли · эмоции · поведение.

### 🗓 Дела (два этапа)

**Утром — план.** `+` → «Дело (план)» → занятие · сфера · когда планирую · важность 0–10 · срочность 0–10. Сохранил → дело уезжает в Google Sheet со статусом `план` и появляется в секции «🗓 План на сегодня» наверху главного экрана.

**По ходу дня — оценка.** Тап по карточке плана → форма с 3 рейтингами: сложность · удовольствие во время · удовлетворение после. Время и важность здесь же можно подправить, если по факту вышло иначе.

Две явные кнопки на выходе:
- **💾 Сохранить (пока в плане)** — частичная оценка, статус остаётся `план`, можно вернуться позже.
- **✅ Готово** — статус → `выполнено`, карточка уходит из плана в общую ленту.

Обе синхронизируются с Google Таблицей (один и тот же ряд обновляется по `entryId`).

### 😊 Настроение (одна запись в день)

Оценки утро/день/вечер по шкале 0–10 со своим комментарием для каждого времени суток, плюс до трёх лекарств с дозировкой (второе и третье — под «Ещё лекарства»). Лекарства подставляются автоматически со вчерашней записи. Календарь настроения (иконка 😊 в шапке) показывает цветные точки по дням. Одна запись на календарный день — при повторном сохранении обновляется тот же ряд.

### 🎯 Цели (мягкое планирование)

Двухуровневая декомпозиция: эпик на месяц → подзадачи на неделю → подзадачи на день. У каждой цели — название, горизонт, дедлайн, заметка; дедлайн можно переносить без чувства вины (счётчик переносов виден в таблице). Из цели одним тапом «Запланировать как дело на сегодня» — создаётся связанная запись в «Делах». Доступ — иконка 🎯 в шапке главного экрана.

## Стек

- **UI:** React 19 + TypeScript + Vite, vite-plugin-pwa
- **Хранилище:** IndexedDB через Dexie, шифрование AES-256-GCM (см. [src/crypto.ts](src/crypto.ts))
- **Голос:** Web Speech API (Chrome на Android — основной таргет), хук [src/hooks/useSpeechRecognition.ts](src/hooks/useSpeechRecognition.ts)
- **Google Sheets:** GIS OAuth2 popup + Sheets REST API, см. [src/utils/gsheets.ts](src/utils/gsheets.ts)
- **PIN-блокировка:** локальный шифр-ключ выводится из PIN, без него записи нечитаемы

## Структура Google Таблицы

Создаются четыре листа автоматически (при первом сохранении соответствующего типа записи — ничего создавать вручную не нужно):

**Эмоции** — `ID · Время · Дата · Триггерная ситуация · Мысли · Эмоции · Поведение`

**Дела** — `ID · Время · Дата · Занятие · Сфера · Важность (0-10) · Срочность (0-10) · Сложность (0-10) · Удовлетворение (0-10) · Удовольствие (0-10) · Статус`

**Цели** — `ID · Родитель · Название · Горизонт · Дедлайн · Статус · Создана · Перенесена (раз) · Заметка`

**Настроение** — `Дата · Утро · Комментарий (утро) · День · Комментарий (день) · Вечер · Комментарий (вечер) · Лекарство 1 · Доза 1 · Лекарство 2 · Доза 2 · Лекарство 3 · Доза 3`

Каждая запись обновляет свой ряд повторно (upsert по `ID`, а для «Настроение» — по `Дата`), а не плодит дубликаты. Колонка «Статус» в «Дела» добавлена в 1.5.0 — старые таблицы продолжают работать, новая колонка просто пишется в свою позицию без заголовка (либо допишите его руками, либо переинициализируйте таблицу).

## Подключение и синхронизация

Подключение делается один раз в ⚙️ Настройках — ссылка на таблицу + вход в Google (пошаговый разбор, включая экран «Google не подтвердил это приложение», — в [руководстве пользователя](docs/GUIDE.md#3-подключение-google-таблицы)).

Синхронизация автоматическая при каждом сохранении. Дневник при этом работает и офлайн: несинхронизированные записи копятся в очереди и досинхронизируются сами, как только вернётся связь (с 1.8.0). В Настройках видно счётчик «⏳ Не синхронизировано: N» и кнопка «🔄 Синхронизировать сейчас» для ручного запуска.
